# Práctica 01 · Git y GitHub

Comandos usados para crear y gestionar los repositorios de la materia desde la terminal:

```bash
git init                         # crear el repositorio local
git branch -M main               # rama principal
git add .                        # preparar cambios
git commit -m "mensaje"          # registrar un commit
git remote add origin <url>      # vincular con GitHub
git push -u origin main          # subir la rama
git status / git log --oneline   # revisar estado e historial
git checkout -b <rama>           # trabajar en una rama nueva
git pull origin main             # traer cambios del remoto
```
