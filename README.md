# Practicas-TQA

Repositorio para organizar las **prácticas, ejercicios y archivos desarrollados durante las clases** de la materia **TQA-711 · Pruebas y Aseguramiento de la Calidad de Software** (UNIFRANZ, 02/2026).

## Organización

Cada práctica va en su propia carpeta numerada con un `README.md` que describe el objetivo, lo realizado y la evidencia.

| Carpeta | Práctica |
|---|---|
| `practica-01-git-github/` | Comandos de Git y GitHub vistos en las exposiciones |
| `practica-02-casos-de-prueba/` | Diseño de casos de prueba (técnicas de caja negra) |
| `plantillas/` | Plantillas reutilizables (caso de prueba, reporte de bug) |
